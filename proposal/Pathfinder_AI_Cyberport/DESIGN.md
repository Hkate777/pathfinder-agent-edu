# DESIGN · Pathfinder AI · Cyberport 大赛计划书

## 全局视觉约定

### ① 画布与安全区
- 画布 1280×720；padding 上下 60、左右 60；内容区 1160×600（x 60–1220，y 60–660）
- 页尾固定在 y=670，字号 14px；封面 / 目录 / 结尾页不设页尾

### ② 配色（深底主题，非蓝紫渐变 / 非绿意）
- 主色（深底）：#0E1A2B（墨蓝）
- 辅色（卡片 / 分隔）：#1B2B40
- 强调色（琥珀）：#F5A623（关键数字、断点点、编号）
- 次强调：#E8863C（渐变末端）
- 底色：#0E1A2B
- 正文色：#E8EDF4；辅助文字：#93A1B5
- 语义色：正确/通过 #35C08C，警示/拒绝 #E05B5B（仅少量使用）
- 面积纪律：主色 ≤60% / 辅色 ≤30% / 强调 ≤10%

### ③ 字体系统
- 中文：Microsoft YaHei（雅黑）；西文：Arial
- 字号阶梯：封面主标 56 / 章节大字 44 / 页面主标 34 / 卡片小标 22 / 正文 18 / 注释 14
- 相邻层级差 ≥4px；正文行高 1.5

### ④ 视觉母题
- 标题下 1px 琥珀细线（贯通标题宽度），只在主标题下出现一次
- 页脚左下 "PATHFINDER AI · CYBERPORT 2026"，右下页码
- 编号用琥珀色

## 逐页规划

### P1 封面 · hero/peak · 全出血 cover.png
- 全屏 cover.png 出血铺底，叠 40–55% 深蓝渐变确保标题可读
- 主标 "每一个错题 / 都是一张学习地图"（56px 白，拆两行）
- 副标 "Pathfinder AI · 错题诊断与个性化复习智能体"（24px）
- 底部一行：教育与文化创意赛道 · 智賦香江 AI 智能體應用大賽 · KK_garden
- anti_pattern: 禁止信息堆砌；禁止等分栏；封面不设页尾页码

### P2 目录 · supporting/transition
- 4 个章节编号 + 标题 + 一行说明，贯通细线分隔
- 01 项目与痛点 / 02 方案与技术 / 03 成果与价值 / 04 佐证与声明
- anti_pattern: 禁止加章节统计条 / 废话块

### P3 项目基本信息 · supporting/valley
- 顶部主标 "项目基本信息"
- 左侧：项目名称 + 一句话定位（放大强调"诊断器，不是解题器"）
- 右侧：团队分工表（4 角色 + 指导老师）
- anti_pattern: 禁止四等分卡片

### P4 行业痛点 · supporting/valley · diagnosis.png 作证据
- 左侧 55%：三张痛点诊断（学生 / 教师 / 现有工具），每张一句话结论 + 支撑
- 右侧 45%：diagnosis.png（圈住断点步骤）
- 底部结论条：错误不可怕，可怕的是不知道错在哪一步
- anti_pattern: 禁止左右 50:50 均分；禁止空泛形容词标题

### P5 核心工作流 · hero/peak · SVG 六步流程
- 主标 "从一张照片到一条复习路径"
- SVG 横向六步流程：解析 → 诊断 → 检索 → 出题 → 排程 → 存储
- 每步独立文本标签，强调"断点步骤"与"阈值判定"两个分叉
- 右侧小卡展示真实诊断 JSON 片段（断点/知识点/置信度）
- anti_pattern: 禁止把文字烤进图形；禁止等宽卡片横排

### P6 典型案例 · supporting/valley
- 主标 "案例：错在去括号，不是算错答案"
- 左侧：学生错误推导三步（中间步用琥珀高亮）
- 右侧：系统输出诊断卡（broken_step / error_type / 知识点 / 置信度）
- 大数字强调：0.8621 grounding 得分
- anti_pattern: 禁止把核心数字塞进角落；禁止无依据套词

### P7 技术创新与安全 · supporting/valley
- 主标 "诚实，是第一创新"
- 五个创新点，每个配一句证据：断点诊断 / grounded 出题 / 诚实失败 / 间隔排程 / 可审计画像
- 底部：闭集分类 + 标注 provider + append-only 三行安全底座
- anti_pattern: 禁止对称罗列"五大优势"空标题；每条必须有证据

### P8 预期成果与价值 · hero/peak · path.png
- 主标 "让一对一诊断成为日常"
- 左侧大数字：14 天重复错误率（核心指标）
- 右侧 path.png（7 节点轨迹）占 50%
- 底部三行：社会价值 SDG4 / 业务价值 SaaS / 可量化指标
- anti_pattern: 禁止巨型数字与解读文字同行挤窄框

### P9 落地路径 · supporting/valley
- 主标 "四阶段落地"
- 横向四阶段时间轴（SVG 节点 + 独立文本）：MVP → 真实模型评测 → 200 人试点 → 本地化与商业化
- 每阶段下方一句可验证产出
- anti_pattern: 禁止四等分卡片；节点文字必须独立可编辑

### P10 评审标准对照 · supporting/valley
- 主标 "对齐评审标准"
- 表格：四维度 + 权重 + 本项目支撑
- 强调 30% 技术创新与安全、25% 场景适配
- anti_pattern: 禁止表格外再堆优势文字

### P11 原创性声明与佐证 · supporting/valley
- 主标 "原创、透明、可复现"
- 左：赛前已有 / 赛期新增 对照；模型、数据、依赖、合规四行
- 右：佐证清单（traces / 44 测试 / 7 样本 + 12 challenge / AGENTS.md）
- anti_pattern: 禁止空泛合规口号

### P12 结尾 · hero/peak
- 深底 + 小面积琥珀点缀
- 主句 "读不清就重拍，匹配不到就如实说——一个自信的错误答案，比没有答案更伤害学生。"
- 代码仓库、团队、提交邮箱
- anti_pattern: 禁止大面积留白无焦点；结尾页不设页尾
